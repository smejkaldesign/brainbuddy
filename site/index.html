A pet for your Claude Code statusline that levels off your own notes


    

      terminalcreature hatches from an egg and grows on a diet of your memories. Every durable note you write is XP.
      It evolves through five forms from Hatchling to Ascendant, across eight species with a 1% shiny roll.
      No streaks, no timers. Feed it or it sits there. It counts your files and never reads them.
    


    

      curl -fsSL https://raw.githubusercontent.com/smejkaldesign/terminalcreature/main/bootstrap.sh | bash

Try the curve

    
How many notes is a Sage?

    
XP is a weighted count of markdown files. Levelling follows a square root, so early notes move the needle hard and later ones don't. Drag the slider.

    

      

      

        
Level 68Sage

        

        
        
700 xp of 1,500 at level 100

        
about 233 durable memories at ×3

        
next form at level 80 (961 xp)

        
level = min(100, floor(100 · sqrt(xp / xp_max)))
The one pace dial is xp_max. Default 1500 puts a well-kept vault around 65. Want the climb to last? config xp_max 5000.

The lifecycle

    
Only two steps need you

    
Hatching the egg, and eventually starting another. Levelling and evolutions happen on their own as your notes pile up.

    

      

        
1

        
Install lays an egg

        
The installer wraps whatever statusline you already have instead of replacing it, then leaves an egg in it. The egg banks XP from the moment it exists, including everything you'd written before.

        curl -fsSL …/bootstrap.sh | bash
      

      

        
2

        
Hatch is a reveal, not a blank slate

        
A short guided setup the first time: where your notes live, whether the existing pile counts, and what to call it. Then the egg opens at whatever level your writing has already earned.

        /creature-hatch
        Zask, a Legendary Nim (shiny) · Lv41 Adept
      

      

        
3

        
Write notes, watch it evolve

        
Every durable note is XP. The caption shows what it ate this session, and the sprite changes shape at levels 20, 40, 60 and 80. Deleting notes never de-levels anyone: the high-water mark only rises.

        🥚 Zask · Adept Lv44 ███░░░ +12 XP
      

      

        
4

        
Fully grown? Lay another

        
Level 100 is the end of the curve. --replace retires the current buddy and keeps its record; --add keeps it around and focuses a new egg. Nothing is ever deleted.

        /creature-new --add
      

    

  






  

    
Built for the statusline

    
Small, polite, and fast on the hot path

    
A statusline redraws on every prompt, so the whole thing is stdlib Python, reads a cache, and gets out of the way.

    

      
┌┐
Wraps, never edits
Your statusline script is never modified. A generated shim runs your command on the same stdin and draws the creature beside it. --uninstall puts everything back.

      
🥚
Eggs bank XP while closed
Waiting costs nothing. A fresh install's first egg inherits the memory you already have, so it usually hatches several forms in.

      
▲
High-water mark
New XP is the delta above the highest total ever seen. Tidying up your notes is never punished.

      
+8
Session counter
Right of the level bar: what your buddy ate in this session, baselined per session id. Hidden until there's something to show.

      
≡
A roster
Keep several creatures. Only the focused one gains; the rest hold their level and wait. focus, rename, retire.

      
◔
Five densities
minimal is one glyph that fills as you evolve. compact, full, the 5-row sprite, or the boxed left column the installer sets up.

      
⬆
Update chip, opt-in
Say yes once and a yellow ⬆ update chip appears when a release is out, from one request a day. Say no and nothing terminalcreature runs ever touches the network.

      
py
Zero dependencies
Stdlib Python 3.9 through 3.13, tested on each in CI. macOS, Linux, and Windows under WSL or Git Bash.

    

  






  

    
Privacy promise

    
It never has your data

    
Short enough to check yourself, and every line is enforced by a test that fails the build.

    

      
Promise
What enforces it

      
✓
Counts your files without opening themThe only filesystem calls are glob and stat. It never reads a byte of a note or parses frontmatter.
A runtime trap patches every file-reading builtin and asserts none fire during a measurement. A static pass tokenizes metric.py and fails if a reader appears at all.

      
✓
Never prints a path it matchedEven doctor reports a home-relative root and counts, not filenames.
A leak guard runs in CI and as a pre-push hook, failing if an absolute home path or a vault-shaped filename reaches the repo.

      
✓
All state is localThe roster, your settings, and the XP cache live at ~/.claude/terminalcreature/. Nothing else, nowhere else.
No accounts, no sync, no server. Tiny per-user JSON, by design.

      
✓
The render never opens a socketNo telemetry, no analytics, no phone-home.
A socket guard covers the render and every background process it spawns. Opted out, an aged cache plus a render produces zero network from any process.

      
✓
The only network calls are the ones you allowedThe installer fetching a release, update and doctor --check by hand, and the once-a-day version check if you opted in.
Every one is an unauthenticated GET of public package metadata that sends nothing about you or your memory. The socket test proves both settings.
